# SQL.FM Feedback

This repository is the public feedback and issue tracker for [SQL.FM](https://sql.fm/), an independent SQL Server feature and compatibility reference.

Use GitHub Issues to report:

* Incorrect feature availability
* Incorrect SQL Server edition or version information
* Incorrect or outdated Microsoft documentation links
* UI or usability problems
* Feature suggestions and improvements

## Before submitting an issue

Please search the existing issues first to see whether the problem has already been reported.

For feature availability corrections, please include:

* The SQL Server feature
* The affected SQL Server version, edition, or Azure environment
* What SQL.FM currently shows
* What you believe it should show
* A Microsoft documentation link when available

Screenshots are also helpful for UI problems.

## About this repository

This repository contains only the public SQL.FM feedback and issue tracker. The SQL.FM application source code is maintained separately.

SQL.FM is an independent reference site and is not affiliated with, endorsed by, or sponsored by Microsoft.
